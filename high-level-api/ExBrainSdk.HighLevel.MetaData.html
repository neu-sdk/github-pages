Parameters

タスク前の事前装着調整フェーズ時間（秒） / Duration of the pre-fitting phase before the task, in seconds.

taskSeconds double

タスクフェーズ時間（秒、負値で手動制御） / Duration of the task phase in seconds (use a negative value to control timing manually).

calmDownSeconds double

postFittingSeconds double

クールダウン後の事後装着調整フェーズ時間（秒） / Duration of the post-fitting phase after calm-down, in seconds.

Remarks

各フェーズ時間は秒単位の小数で指定できる（例: 10 Hz 計測で 0.1 秒 = 1 フレーム）。各フェーズのフレーム数は実際に受信したフレームで決まるため、指定時間 × サンプリング周波数から ±1 フレーム程度ずれることがある / Phase durations are in seconds and may be fractional (e.g. 0.1 s = one frame at 10 Hz). The frame count of each phase is determined by the frames actually received, so it can differ by about one frame from duration × sampling rate.
