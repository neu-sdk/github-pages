ExBrainSDK の概要

本ソフトウェア開発キット ExBrainSDK（以下、本SDK）は、Windows OSをターゲットとしている。また、本SDKは「HOT-2000」装置もしくは「XB-01」装置を対象とし、SDK1つに対して装置1台の接続を基本とする。 ユーザーアプリケーション（以下、ユーザーアプリ）にて複数ユーザーと接続し各種計測結果を収集する場合は、本SDK内の特定クラスのインスタンスを複数使用することで実現可能とする。

本ドキュメントは、一般ユーザーが第2世代小型NIRS装置(以下、装置)を使用した脳活動計測に関するアプリケーション作成時に容易に組み込み、且つ、装置の操作を可能する為のソフトウェア開発キット「ExBrainSDK」に適用するものとする。
※NIRS: Near Infra-Red Spectroscopy(近赤外分光法)

ExBrainSDK の構成

ExBrainSDK は以下のような機能で構成されます。APIはHigh-Level と Low-Level の2層に分かれております。

機能 説明
Low-Level API 装置検索、接続、計測、データ取得、記録といった基礎的な機能を提供します。
High-Level API アプリケーション開発を容易にするための便利な機能を提供します。High-Level APIは内部でLow-Level APIを呼び出しています。
LowLevelSample Low-Level API だけを用いて構成された、一連の流れを実行するコンソールアプリ。装置選択と接続・計測開始・計測終了・装置切断のステップをキー入力による対話形式で操作して進めていきます。PowerShell 用いて実行することを推奨します（他ターミナルでは、終了時に自動的に閉じてしまうケースが発生します）。サンプルコードはLow-Level API のセクションをご確認ください。.NET がインストールされている環境では、SDK の LowLevelSample フォルダで dotnet run を実行することでサンプルを起動できます。生成される実行ファイルは LowLevelSample.exe です。
HighLevelSample 主にHigh-Level API を用いて構成された、一連の流れを実行するコンソールアプリ。　PowerShell 用いて実行することを推奨します（他ターミナルでは、終了時に自動的に閉じてしまうケースが発生します）。サンプルコードはHigh-Level API のセクションをご確認ください。.NET がインストールされている環境では、SDK の HighLevelSample フォルダで dotnet run を実行することでサンプルを起動できます。生成される実行ファイルは HighLevelSample.exe です。
NeULicenseManager SDKやアプリを利用するためのライセンスキーを登録したり無効化するための管理アプリのインストーラー。
