NIRSの基本

信号処理と解析方法

NIRS信号は、脳活動に伴う血液量変化を計測しています。しかし、これには脈波などの脳活動に由来しない信号も含まれます。タスクや刺激提示を開始すると血液量は5～7秒かけて増加し、止めると15～25秒（リカバリ期間）かけてベースラインに戻ります。これがタスク/刺激に関係する脳活動に由来した信号成分です。

これ以外に、１Hz程度（安静時）の脈波、0.3Hz程度の呼吸成分がNIRS信号に現れます。脈波と呼吸の成分は、脳活動に由来する信号に比べて高い周波数を有するため、ローパスフィルタを用いて除去できます。更に、メイヤー波（0.1 Hz付近）などの生理活動に伴う低周波の血液量変動成分も存在します。また、脳は常に活動しているので、タスク/刺激に関係しないバックグラウンド脳活動による信号も観測されます。これらの信号を除去するには、ハイパスフィルタや同期検波の手法が用いられます。一般に周波数フィルタを掛けると、信号波形の両端が歪みます。計測時間を十分長くとれない場合には、この歪の影響が無視できなくなるので、ハイパスフィルタではなく、ベースラインを直線近似して減算するなど別の方法が選択されます。

同期検波とは、前レスト期間＋タスク/刺激期間＋後レスト期間を１つのブロックとして、これを繰返し、その繰返しに同期して変動する信号成分を抽出する手法です。ここで、注目するタスク/刺激の無い状態をレストと呼びます。前レスト期間はベースライン補正の方法によって適切な時間を決めます。タスク開始時の１点を用いてベースラインとするならばその１点だけでも構いませんが、数秒程度の前レスト期間を設けてベースライン補正に使います。タスク/刺激時間はその種類によってケースバイケースですが、継続したタスクを行う場合には、上記血液の立ち上がり時間より長くとると信号強度が大きくなります。後レストは上記リカバリ時間にベースライン補正用の時間を加えた期間とします。リカバリ時間が十分に取れない場合は、異なる解析法が必要になりますが本SDKでは対応していません。ここで示した時間は、あくまで目安であり、実際に使うタスク/刺激を用いて計測し、適用可能性と要求精度を考慮して定めるようにして下さい。

得られた信号波形をブロック毎に切り出し加算平均すると、繰返しに同期しない信号成分は位相がずれているため重ね合わせにより減少し、同期する成分、つまりタスク/刺激に関連して変動する信号成分を抽出することができます。更に、レスト期間に比べてタスク/刺激期間の信号が有意に変化しているかどうかを調べるには、平均値差検定を行います。 繰返し計測を行わない場合でも、NIRS信号はその計測原理上、ある時点の値からの増量または減少量しか得られませんので、必ず信号の原点を決める必要があります。装置出力は、便宜的に計測開始時を0とすることが多いですが、前述のようにベースラインのゆらぎが大きいため、注目する脳活動を生じさせるタスクまたは刺戟の開始前の値または時間平均値を基準に取り直すことが一般的です。 High-Level APIは、上記信号前処理と同期検波に対応した信号処理および解析を行なう機能を有します。これまで信号解析は計測後に行うことしかできませんでしたが、本APIを用いることにより、計測中に解析を実施して、その結果を用いて次の計測条件を選択するなど、リアルタイム性を備えたアプリを容易に作成することができます。

本SDKでは、NIRS信号を取得するためのLow-Level APIとNIRS信号を適切に扱うためのHigh-Level APIを用意しています。
