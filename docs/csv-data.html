出力CSVデータ

CSVデータの項目について

計測が終了するとCSVデータが出力されます。

Low-Level API による基本データを記録したCSVファイルと、High-Level API による解析結果を含むCSVファイルとの２種類が存在します。

それぞれのCSVファイルにおける、データ項目について説明します。

Low-Level CSV

Low-Level APIから出力されるCSVデータの項目です。

計測モードによるデータの違い

計測サイクル（10Hz / 50Hz / 100Hz / 500Hz）によって、1フレームあたりのデータ内容が異なります。

  • 10Hz モード: 全項目が出力されます。
  • 50Hz / 100Hz / 500Hz モード（高速サンプリングモード）: 各フレームには左チャンネルの生体光センサーデータのみが含まれます。右チャンネルデータ・IMUデータ・飽和カウンタ・カラーインデックス・心拍数・ノイズ検出フラグは常に 0 となります。BatteryVolt / BatteryRemain は計測開始時点の値が全フレームに固定で記録されます。また、このモードではCSVファイル名の末尾に _fast が付加されます。

下表の「高速サンプリング」列は、50Hz / 100Hz / 500Hz モードでの出力可否を示します（○: 有効値あり、0: 常に0）。
