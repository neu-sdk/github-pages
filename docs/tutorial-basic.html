チュートリアル：デバイスの検索から計測データ取得まで

このチュートリアルでは、サンプルコード tutorial.cs を例に、Low-Level API を使って以下のステップを順に実装する方法を説明します。

  1. API の初期化
  2. デバイスの検索と接続
  3. ゲイン調整
  4. キャリブレーション
  5. 計測の開始とデータ受信
  6. 計測の停止と切断

各ステップのコードは tutorial.cs の該当部分の抜粋です。末尾の「コード全体」に tutorial.cs の完全なコードを掲載しています。

コンソール出力のプレフィックス

このチュートリアルのコードでは、コンソール出力に以下のプレフィックスを付けてメッセージの種類を識別できるようにしています。

プレフィックス 用途
[SDK] SDK からの状態変化通知
[LOG] SDK 内部ログ
[OK] 処理成功
[ERROR] 処理失敗
[DATA] 計測データ出力
なし ユーザーへの案内・操作指示

前提条件

  • .NET 8.0 以上
  • ExBrain SDK の NuGet パッケージを参照済み
  • デバイスが PC と Bluetooth または USB で接続済み（Bluetooth の場合はペアリング済み）

起動方法

SDK の Tutorial フォルダに本チュートリアルのプログラム（tutorial.cs）が掲載されています。 .NET がインストールされている環境では、Tutorial フォルダで以下のコマンドを実行すると tutorial.cs を起動できます。

dotnet run

ステップ 1: API の初期化

// ▼ Main() の中
var api = new ExBrainApi(
    notifyStatusChangedCallBack: (id, status) => Console.WriteLine($"[SDK] ID: {id}  Status: {status}"),
    notifyProcessMessageCallBack: (id, message, type) => Console.WriteLine($"[LOG] ID: {id}  [{type}] {message}")
);

// ▼ Run() の中
EnmSdkResult sdkResult = api.InitApi(
    needOutputTraceLog: true,
    needOutputCommLog: false,
    logDir: null,       // ログファイルの出力先フォルダ。null の場合はカレントディレクトリ
    settingsDir: null,  // 設定ファイルの読み込み先（未実装）
    tag: ""             // 識別タグ（未実装）
);
if (sdkResult != EnmSdkResult.eSuccess)
{
    Console.WriteLine("[ERROR] API の初期化に失敗しました。");
    return;
}

logDir にフォルダパスを指定するとトレースログファイルが出力されます。null の場合はカレントディレクトリに出力されます。

ステップ 2: デバイスの検索と接続

await api.ResetBluetoothModuleAsync();

api.StartSearchDevice(new ExBrainSearchParameter
{
    Keywords = ["HOT", "XB"],
    ShouldUSB = true,
    ShouldPairedBluetooth = true,
    ShouldNonPairedBluetooth = true,
    TimeoutSecond = 3
});
await Task.Delay(TimeSpan.FromSeconds(3));
api.StopSearchDevice();

if (api.DiscoveredDevice.DeviceCount == 0)
{
    Console.WriteLine("[ERROR] デバイスが見つかりませんでした。");
    return;
}

// 検出されたデバイスを一覧表示する
IReadOnlyList<DeviceInformationEx> devices = api.DiscoveredDevice.Devices;
Console.WriteLine("検出されたデバイス一覧:");
for (int i = 0; i < devices.Count; i++)
{
    Console.WriteLine($"  番号 {i}: 種類={devices[i].ConnectType}  ID={devices[i].DeviceId}");
}

// 接続するデバイスを選択する
Console.WriteLine($"接続する番号を入力してください (0 ～ {devices.Count - 1}):");
string? indexInput = await Console.In.ReadLineAsync();
if (!int.TryParse(indexInput, out int selectedIndex) || selectedIndex < 0 || selectedIndex >= devices.Count)
{
    Console.WriteLine("[ERROR] 番号が正しくありません。");
    return;
}

sdkResult = await api.ConnectDeviceAsync(devices[selectedIndex].DeviceId, devices[selectedIndex].ConnectType);
if (sdkResult != EnmSdkResult.eSuccess)
{
    Console.WriteLine("[ERROR] 接続に失敗しました。");
    return;
}

Console.WriteLine("[OK] 接続しました。");

ステップ 3: ゲイン調整

ゲイン調整は光センサーの出力レベルを最適化する処理です。計測前に毎回実施してください。

// 装着確認
Console.WriteLine("デバイスを額に装着してください。");
Console.WriteLine("センサーユニットが眉の上に来るように装着し、髪の毛が挟まらないように注意してください。");
Console.WriteLine("装着が完了したら Enter キーを押してください。");
_ = await Console.In.ReadLineAsync();

// ゲイン調整
Console.WriteLine("ゲイン調整を開始します。準備ができたら Enter キーを押してください。");
_ = await Console.In.ReadLineAsync();
sdkResult = await api.PerformGainAdjustmentAsync(api.HandleId);
if (sdkResult != EnmSdkResult.eSuccess)
{
    Console.WriteLine("[ERROR] ゲイン調整に失敗しました。");
    await api.DisconnectDeviceAsync();
    return;
}
Console.WriteLine("[OK] ゲイン調整が完了しました。");

ステップ 5: 計測の開始とデータ受信

計測データは 10Hz（1秒に10回）でコールバックされます。毎フレーム出力するとコンソールが流れるため、ここでは5フレームに1回表示します。

Console.WriteLine("計測を開始します。計測中は Enter キーで停止できます。");
Console.WriteLine("準備ができたら Enter キーを押してください。");
_ = await Console.In.ReadLineAsync();

var receivedData = new List<ExBrainMeasureData>();
int frameCount = 0;

sdkResult = await api.StartMeasureAsync(
    handleId: api.HandleId,
    measureLogFolder: "./",   // CSV ログをカレントディレクトリに出力する
    callback: (_, data) =>
    {
        receivedData.Add(data);
        frameCount++;

        // 5フレームに1回だけコンソールに出力する
        if (frameCount % 5 == 0)
        {
            Console.WriteLine(
                $"[DATA][{frameCount}] " +
                $"左 1cm: {data.dTHbL_leftSD1cm:F4}  " +
                $"左 3cm: {data.dTHbL_leftSD3cm:F4}  " +
                $"右 1cm: {data.dTHbL_rightSD1cm:F4}  " +
                $"右 3cm: {data.dTHbL_rightSD3cm:F4}"
            );
        }
    },
    measurementCycle: EnmSdkMeasurementCycle.e10Hz,
    measurementMode: EnmSdkMeasurementMode.eNormal
);

if (sdkResult != EnmSdkResult.eSuccess)
{
    Console.WriteLine("[ERROR] 計測の開始に失敗しました。");
    await api.DisconnectDeviceAsync();
    return;
}

// Enter キーが押されるまで計測を継続する
_ = Console.ReadLine();

measureLogFolder にフォルダパスを指定すると HOTLog_YYYYMMDD_HHMMSS.csv が自動出力されます。CSV が不要な場合は null を渡してください。

コールバック内で受け取れる主なデータは以下のとおりです。

プロパティ 内容
dTHbL_leftSD1cm 左チャンネル 1cm のヘモグロビン濃度変化
dTHbL_leftSD3cm 左チャンネル 3cm のヘモグロビン濃度変化
dTHbL_rightSD1cm 右チャンネル 1cm のヘモグロビン濃度変化
dTHbL_rightSD3cm 右チャンネル 3cm のヘモグロビン濃度変化
SamplingMotion モーションセンサーデータ（加速度・ジャイロ）
SamplingBattery バッテリー情報

注意: v3.1.0 では EnmSdkMeasurementCycle.e10Hz と EnmSdkMeasurementMode.eNormal の組み合わせのみ対応しています。

ステップ 6: 計測の停止と切断

sdkResult = await api.StopMeasureAsync(api.HandleId);
if (sdkResult != EnmSdkResult.eSuccess)
{
    Console.WriteLine("[ERROR] 計測の停止に失敗しました。");
}

await api.DisconnectDeviceAsync();
Console.WriteLine($"[OK] 計測終了。受信フレーム数: {receivedData.Count}");

api.ExitApi() はコード全体の Main() で呼び出されます。

コード全体（tutorial.cs）

using ExBrainSdk;
using ExBrainSdk.Datas;
using ExBrainSdk.Enumerations;

internal class Program
{
    private static void Main()
    {
        var api = new ExBrainApi(
            notifyStatusChangedCallBack: (id, status) => Console.WriteLine($"[SDK] ID: {id}  Status: {status}"),
            notifyProcessMessageCallBack: (id, message, type) => Console.WriteLine($"[LOG] ID: {id}  [{type}] {message}")
        );

        Run(api).Wait();
        api.ExitApi();

        Console.WriteLine("Press any key to quit");
        _ = Console.ReadKey();
    }

    public static async Task Run(ExBrainApi api)
    {
        // 初期化
        EnmSdkResult sdkResult = api.InitApi(
            needOutputTraceLog: true,
            needOutputCommLog: false,
            logDir: null,
            settingsDir: null,
            tag: ""
        );
        if (sdkResult != EnmSdkResult.eSuccess)
        {
            Console.WriteLine("[ERROR] API の初期化に失敗しました。");
            return;
        }

        await api.ResetBluetoothModuleAsync();

        // デバイス検索
        api.StartSearchDevice(new ExBrainSearchParameter
        {
            Keywords = ["HOT", "XB"],
            ShouldUSB = true,
            ShouldPairedBluetooth = true,
            ShouldNonPairedBluetooth = true,
            TimeoutSecond = 3
        });
        await Task.Delay(TimeSpan.FromSeconds(3));
        api.StopSearchDevice();

        if (api.DiscoveredDevice.DeviceCount == 0)
        {
            Console.WriteLine("[ERROR] デバイスが見つかりませんでした。");
            return;
        }

        // 接続するデバイスを選択する
        IReadOnlyList<DeviceInformationEx> devices = api.DiscoveredDevice.Devices;
        Console.WriteLine("検出されたデバイス一覧:");
        for (int i = 0; i < devices.Count; i++)
        {
            Console.WriteLine($"  番号 {i}: 種類={devices[i].ConnectType}  ID={devices[i].DeviceId}");
        }
        Console.WriteLine($"接続する番号を入力してください (0 ～ {devices.Count - 1}):");
        string? indexInput = await Console.In.ReadLineAsync();
        if (!int.TryParse(indexInput, out int selectedIndex) || selectedIndex < 0 || selectedIndex >= devices.Count)
        {
            Console.WriteLine("[ERROR] 番号が正しくありません。");
            return;
        }

        sdkResult = await api.ConnectDeviceAsync(devices[selectedIndex].DeviceId, devices[selectedIndex].ConnectType);
        if (sdkResult != EnmSdkResult.eSuccess)
        {
            Console.WriteLine("[ERROR] 接続に失敗しました。");
            return;
        }
        Console.WriteLine("[OK] 接続しました。");

        // 装着確認
        Console.WriteLine("デバイスを額に装着してください。");
        Console.WriteLine("センサーユニットが眉の上に来るように装着し、髪の毛が挟まらないように注意してください。");
        Console.WriteLine("装着が完了したら Enter キーを押してください。");
        _ = await Console.In.ReadLineAsync();

        // ゲイン調整
        Console.WriteLine("ゲイン調整を開始します。準備ができたら Enter キーを押してください。");
        _ = await Console.In.ReadLineAsync();
        sdkResult = await api.PerformGainAdjustmentAsync(api.HandleId);
        if (sdkResult != EnmSdkResult.eSuccess)
        {
            Console.WriteLine("[ERROR] ゲイン調整に失敗しました。");
            await api.DisconnectDeviceAsync();
            return;
        }
        Console.WriteLine("[OK] ゲイン調整が完了しました。");

        // キャリブレーション
        Console.WriteLine("キャリブレーションを開始します。準備ができたら Enter キーを押してください。");
        _ = await Console.In.ReadLineAsync();
        sdkResult = await api.PerformCalibrationAsync(api.HandleId);
        if (sdkResult != EnmSdkResult.eSuccess)
        {
            Console.WriteLine("[ERROR] キャリブレーションに失敗しました。");
            await api.DisconnectDeviceAsync();
            return;
        }
        Console.WriteLine("[OK] キャリブレーションが完了しました。");

        // 計測開始確認
        Console.WriteLine("計測を開始します。計測中は Enter キーで停止できます。");
        Console.WriteLine("準備ができたら Enter キーを押してください。");
        _ = await Console.In.ReadLineAsync();

        var receivedData = new List<ExBrainMeasureData>();
        int frameCount = 0;

        sdkResult = await api.StartMeasureAsync(
            handleId: api.HandleId,
            measureLogFolder: "./",
            callback: (_, data) =>
            {
                receivedData.Add(data);
                frameCount++;
                if (frameCount % 5 == 0)
                {
                    Console.WriteLine(
                        $"[DATA][{frameCount}] " +
                        $"左 1cm: {data.dTHbL_leftSD1cm:F4}  " +
                        $"左 3cm: {data.dTHbL_leftSD3cm:F4}  " +
                        $"右 1cm: {data.dTHbL_rightSD1cm:F4}  " +
                        $"右 3cm: {data.dTHbL_rightSD3cm:F4}"
                    );
                }
            },
            measurementCycle: EnmSdkMeasurementCycle.e10Hz,
            measurementMode: EnmSdkMeasurementMode.eNormal
        );

        if (sdkResult != EnmSdkResult.eSuccess)
        {
            Console.WriteLine("[ERROR] 計測の開始に失敗しました。");
            await api.DisconnectDeviceAsync();
            return;
        }

        _ = Console.ReadLine();

        // 計測停止・切断
        sdkResult = await api.StopMeasureAsync(api.HandleId);
        if (sdkResult != EnmSdkResult.eSuccess)
        {
            Console.WriteLine("[ERROR] 計測の停止に失敗しました。");
        }

        await api.DisconnectDeviceAsync();
        Console.WriteLine($"[OK] 計測終了。受信フレーム数: {receivedData.Count}");
    }
}
