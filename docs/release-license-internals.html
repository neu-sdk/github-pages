リリースライセンスの内部仕様

このページは、ExBrain SDK のリリースライセンス実装を管理しているNeU社向けのドキュメントになります。

概要

リリースライセンスはマシン ID ではなく、特定のアプリバージョンに紐付けられます。署名済みライセンスには AppHash フィールドが含まれています。リリースライセンスの場合、NeU License Manager はカノニカルハッシュとアプリ検証 JSON の両方を含む AppHash ペイロードを送信します。サーバーはそのペイロードをライセンスに署名します。実行時、SDK は AppHash を持つライセンスについて、署名されたペイロードのハッシュが埋め込まれた JSON と一致し、その JSON にリストされたすべてのファイルが記録された SHA-256 ハッシュと一致する場合にのみ有効とみなします。

JSON が存在しない場合、JSON ハッシュが署名済みペイロードハッシュと一致しない場合、またはリストされたファイルのいずれかが欠落または変更されている場合、SDK はライセンスを AppInvalid とマークします。

リリースライセンスの検証は意図的にローカルかつオフラインで行われます。実行時の機能チェックはライセンスサーバーを呼び出しません。再アクティベーション/非アクティベーション API は、アプリまたはツールがエンドユーザーの PC をサーバー側に表示させたい場合や、同期中に失効を検出したい場合に引き続きサーバーに接続できます。

アプリバインディングアルゴリズム

検証データは構造化された JSON ですが、ハッシュは生の JSON バイトに対して計算されません。これにより、ホワイトスペースとプロパティ順序の問題を回避しています。

SDK は JSON を解析し、files を相対パスでソートした後、次のカノニカルペイロードを再構築します：

{"algorithm":"sha256","canonicalization":"neu-app-fingerprint-v1","entryPoint":"...","files":[{"path":"...","sha256":"...","size":123}],"rootType":"directory","schema":"com.neu.exbrain.app-fingerprint","schemaVersion":1}

AppHash は以下のとおりです：

sha256(canonical UTF-8 payload)

新しいリリースライセンスの場合、サーバーの appHash パラメーターに送信される値は JSON 文字列です：

{"schema":"com.neu.exbrain.apphash-v1","schemaVersion":1,"hash":"<sha256>","json":"<app validation JSON>"}

サーバーはこの完全な文字列をライセンスの AppHash フィールドに署名します。

各ファイルのハッシュは以下のとおりです：

sha256(raw file bytes)

相対パスは常に / を使用し、序数順でソートされます。絶対パスや .. を含むパスは使用できません。

実行時のルックアップ

インストール済みライセンスは両方のレジストリハイブから読み込まれます：

  • HKCU\Software\NeU\Licenses
  • HKLM\Software\NeU\Licenses

NeU License Manager によってアクティベートされた開発者ライセンスは HKCU に書き込まれます。エンドユーザー向けリリースライセンスは、アプリ開発者のインストーラーによって HKLM にインストールされる必要があります。

SDK はまず、署名済み AppHash ペイロードに埋め込まれた検証 JSON を確認します。古い生成ライセンスとの互換性のため、次の場所で平文の 64 文字 AppHash に対応する検証 JSON も検索します：

  • HKCU\Software\NeU\AppFingerprints\<appHash>
  • HKLM\Software\NeU\AppFingerprints\<appHash>
  • 値 ManifestJson：NeuAppFingerprint.json の完全なコンテンツ
  • 値 AppRoot：JSON 相対パスの解決に使用するインストール済みアプリケーションルートディレクトリ
  • 環境変数オーバーライド NEU_APP_FINGERPRINT_JSON（オプションで NEU_APP_ROOT）
  • プロセス実行ファイルの隣にある NeuAppFingerprint.json
  • ExBrainSdkNative.dll の隣にある NeuAppFingerprint.json
  • 現在の作業ディレクトリの NeuAppFingerprint.json

埋め込みペイロードライセンスの場合、SDK は実行中の実行ファイルのディレクトリ、ExBrainSdkNative.dll のディレクトリ、現在の作業ディレクトリ、および NEU_APP_ROOT をアプリルートとして試みます。

ライセンス有効性ルール

通常の開発者ライセンスは既存のマシンバインド動作を維持します。

リリースライセンスは AppHash の存在によって検出されます：

  • 空の Guid：Corrupted
  • 期限切れライセンス：Expired
  • AppHash が存在し、JSON/ファイルが一致：Valid
  • AppHash が存在するが、JSON/ファイルの検証失敗：AppInvalid
  • AppHash なしでマシン ID が不一致：InvalidHardware

リリースライセンスは意図的に MachineId を必要としません。

現在の実装は MachineId の前に AppHash を確認するため、MachineId のないリリースライセンスは検証 JSON とアプリファイルが一致する限り有効です。
