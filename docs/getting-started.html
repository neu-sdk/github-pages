開発・動作環境

本SDKは、.NET 8.0以上での利用を推奨しています。動作環境および通信要件は以下の通りです。

  • 対応OS：
    • Windows 10 (64bit)
    • Windows 11 (64bit)
  • 対応フレームワーク：
    • .NET 8.0以上
    • 互換性確保のため、.NET Standard 2.1にも対応
    • ※.NET Frameworkには対応していません。
  • 通信要件：
    • 対応インターフェース： Bluetooth 4.1 以上 または USB 2.0 以上
    • Bluetoogh 接続時：fNIRSセンサーデバイスが PC と正常にペアリングされている必要があります。
    • USB 接続時：fNIRSセンサーデバイスがPCに接続され、デバイス用ドライバが正常にインストールされている必要があります。
